# Cloud Server Health Monitor & Automation

A lightweight Linux cloud automation project built using Python and Cron.

## Features
- **Disk Space Auditing:** Monitors available server storage using Python's `shutil` module.
- **Persistent Logging:** Records ISO-timestamped health checks directly to `server_health.log`.
- **Scheduled Automation:** Runs in the background every minute via the Linux `cron` daemon.

## Tech Stack
- **OS:** Linux (Ubuntu)
- **Language:** Python 3
- **Tools:** Cron Daemon, Git, GitHub
